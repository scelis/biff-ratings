# Biff Ratings

A simple site for displaying ratings from [Biff!](https://www.theincomparable.com/biff/), a podcast on [The Incomparable](https://www.theincomparable.com/).

## Dependencies

All dependencies are loaded directly from [jsDelivr](https://www.jsdelivr.com).

| Library | Version | Use |
|---|---|---|
| [Chart.js](https://www.chartjs.org/) | 4 | Line chart and pie charts |
| [chartjs-plugin-zoom](https://www.chartjs.org/chartjs-plugin-zoom/) | 2.0.1 | Zoom and pan on the ratings chart |
| [Hammer.js](https://hammerjs.github.io/) | 2.0.8 | Touch gesture support (required by chartjs-plugin-zoom) |

## Hosting

The site is plain HTML/CSS/JS and can be served from any static file host.
